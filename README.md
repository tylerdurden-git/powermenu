# PowerMenu (Win + X for Linux / GNOME)

A lightweight shortcut popup for GNOME inspired by the Windows `Win + X` menu.

## Hotkeys

| Key | Action |
|:---:|:---|
| `t` | Task Manager |
| `x` | Terminal |
| `n` | Toggle Night Light |
| `m` | Toggle Mic Mute |
| `a` | Toggle Audio Output Mute |
| `d` | Toggle Do Not Disturb |
| `l` | Lock Screen |
| `k` | Log Out |
| `s` | Suspend / Sleep |
| `r` | Restart |
| `u` | Shut Down |
| *Any other key / Click outside* | Dismiss |
